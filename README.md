## About

I like turning messy data into something a model — or a person — can actually use. Most days that means digging through datasets, arguing with SQL, or figuring out why a pipeline broke right before a deadline. I'm equally happy building the model as I am explaining what it's doing and why anyone should trust it.

When I'm not doing that, I'm probably solving a LeetCode problem out of stubbornness rather than necessity, or rebuilding a small web project just to see if I can make it cleaner the second time around.

## Projects

**Centralized Feature Store for Viewership**
A centralized feature-store pipeline for user viewership data. Organizes raw watch-event data into reusable feature groups — engagement, genre affinity, watchtime history, device profile, and subscription profile — registers them in a catalog, and materializes daily features for downstream ML models such as churn/inactivity prediction and watch-time forecasting.
- Feature registry, definitions, and materialization logs backed by MySQL
- Python-based feature-building and backfill scripts
- SQL-driven schema definition and catalog management
- File-based storage for raw logs and generated feature outputs

**Hotel Booking Demand — ML Project**
A machine learning notebook that analyzes hotel booking data and predicts whether a booking will be canceled.
- Cleaned missing values and duplicates, explored patterns through visualization
- Trained and evaluated classification models to predict cancellation
- Built with pandas, numpy, matplotlib, seaborn, and scikit-learn

**Zomato EDA**
An exploratory data analysis of the Zomato restaurants dataset, focused on extracting meaningful insights about restaurant data and customer preferences.
- Cleaned and restructured real-world data
- Analyzed country-wise restaurant distribution, ratings, currencies, delivery availability, and city/cuisine trends
- Communicated findings through purpose-built visualizations

**Web Development**
A collection of small full-stack web experiments, progressing from static pages to REST APIs with NLP-powered features.
- Static HTML/CSS/JS pages and a login UI
- Flask apps with server-rendered templates
- FastAPI apps with REST endpoints and Pydantic models
- Sentiment analysis integration using TextBlob

A running archive of problem-solving practice and solutions.
