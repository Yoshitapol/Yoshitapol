# 📂 Featured Projects

## 📊 Centralized Feature Store for Viewership

A centralized feature engineering pipeline designed to organize raw user viewership events into reusable feature groups for downstream Machine Learning models.

### Highlights

- Designed reusable feature groups for user behaviour analysis
- Generated daily feature materialization pipelines
- Maintained a centralized feature catalog using MySQL
- Built feature generation scripts using Python
- Created feature groups including:
  - User Engagement
  - Genre Affinity
  - Watch Time History
  - Device Profile
  - Subscription Profile
- Designed for ML use cases such as:
  - Churn Prediction
  - User Inactivity Prediction
  - Watch Time Forecasting
